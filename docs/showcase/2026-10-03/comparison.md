# 本機 Blender MCP 與 Your dot：怎樣選擇

[返回圖集](../README.md) · [貼文草稿](post-copy.zh-Hant.md)

**重點是把對話接回自己的 Blender 製作環境。** 這不是「本機一定比雲端快」或「不用付 AI 用量」的比較。以下以本案例已測過的 MCP 工作方式，對照官方描述的 Your dot 功能；未做同一任務的效能或扣額測試。

| 比較項目 | Blender Web Bridge／本機 Blender MCP | Your dot |
| --- | --- | --- |
| 主要用途 | 專注操作 Blender 場景、材質、相機及渲染 | 跨工具處理任務，也可連接個人電腦及插件 |
| 工作環境 | 使用自己設定的本機 Blender | 有雲端電腦；接駁本機後也可使用本機檔案及工具 |
| 既有素材／插件 | 可沿用目標環境已有的資產與插件，但要啟用及個別驗證 | 取決於工作環境和已連接的工具，不能說完全不能用本機插件 |
| 算力 | Blender 渲染使用所選本機設備；可掌握硬體、版本及設定 | 視任務在雲端還是已連接電腦執行而定 |
| 開機要求 | 本機 Blender／通道需保持可用 | 純雲端工作可在雲端進行；依賴本機的部分仍需電腦在線 |
| 用量 | 日常可在 ChatGPT 網頁操作，不需要 Codex 中轉；模型用量不會消失 | 依產品、方案、模型與任務計算；不能直接假設比較貴 |
| 代價 | 要自己設定、維護連線及照顧本機負載；錯誤可影響真實場景 | 要管理工具／電腦授權；本機接駁、環境限制及用量同樣要留意 |

Your dot 也能接駁本機，以上不是二選一的互斥比較。其官方說明：[Connect computers and apps to your dot](https://learn.chatgpt.com/docs/dots/computers-and-apps)。本例未驗證「Your dot＋此特定 MCP」的完整組合。

## 為甚麼選這個工具

對已有 Blender 工程、素材庫、插件及製作習慣的人，這個專用接駁方式有實際價值：對話完成後仍是可接手修改的 `.blend`；工作留在自己熟悉的環境，場景建構、燈光及相機可持續調整。是否省時要看任務與返工量；硬體更強不代表每次都更快，也不會加快雲端模型本身的推理。

本次較有說服力的案例是[遊戲廳](arcade.md)和[列車月台場景](../2026-09-29/train.md)。直接生成寫實人物效果不足；建議先用專用角色工具準備模型與骨架，再回到 Blender 安排姿勢和場景，詳見月台案例。

## 能否說「不燒 Codex Token」

建議寫：**「不用另外開 Codex，也能在 ChatGPT 網頁直接操作本機 Blender。」**

這說的是操作流程，不是扣額保證。官方的 Codex 定價文件描述共用用量及按模型／任務計算；部分組織的 Work 使用共享 credits。這些規則不能一概推成每個個人帳戶的普通 ChatGPT 對話都扣同一個餘額。本案例沒有記錄同任務的前後扣額，不能宣稱「零 Codex 消耗」「免費無限用」或「必定比 dot 省 Token」。來源：[用量說明](https://learn.chatgpt.com/docs/pricing)、[Work credits 的適用範圍](https://learn.chatgpt.com/docs/enterprise/chatgpt-work-usage-and-cost)。

## 官方會不會禁止？

OpenAI 有正式的 [Secure MCP Tunnel 文件](https://developers.openai.com/api/docs/guides/secure-mcp-tunnels)，用途正是把私人 MCP 接到支援的產品。**這種接駁方式本身有官方技術支援；不等於我們這個第三方工具經官方認證，也不保證任何帳戶永遠可用或不會受限制。**

目前發布的是 GitHub 原始碼，供使用者在自己的合資格帳戶、通道和本機環境設定。官方明列 Secure MCP Tunnel 支援私人接駁／開發者測試，**不支援以 Tunnel 作公開插件提交或分發入口**。因此不能宣傳成「官方插件商店已上架」或共用一組通道／金鑰讓所有人直接使用。

便利的原因是分工：模型透過工具發出操作，Blender 在本機執行。不是繞過付費、地區資格、權限或安全限制的漏洞。

## 真正要留意的風險

- MCP 能在 Blender 執行程式碼，Safe Mode 不是 OS 沙盒；應使用可信任的工具並保留工程備份。
- 本機運算不等於完全離線。提示詞、參考圖及工具回覆仍會交給雲端產品處理。
- 本機需保持在線；連線中斷、模型操作錯誤及渲染占用資源都有可能發生。
- 資格、權限、產品規則及收費可能改變；有官方接法不代表「永不封鎖」保證。
