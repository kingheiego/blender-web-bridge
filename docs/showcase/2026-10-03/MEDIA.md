# 圖片來源與使用範圍

這批圖片由提供者於 2026-10-04 要求放到此 GitHub 作案例展示。此處的展示許可不等於另行授予通用圖片重用授權；程式碼的 MIT 授權不自動適用於參考相片及案例圖像。

- `street-reference.jpg`：使用者提供的參考相片。只移除 EXIF、XMP、IPTC 和文字附加資料；保留顏色描述，並核對解碼後像素完全相同。未另外修改人物或場景。
- 六張成果 PNG：由 ChatGPT 網頁版透過本機 Blender 工作流程產生的實際渲染。移除可能含私人路徑的 metadata，保留原尺寸及原始圖像像素。
- 三張操作 JPEG：實際 ChatGPT／Blender 畫面；只使用已檢視且沒有私人路徑或憑證的版本。Blender 畫面標示為渲染檢視，不用它單獨證明整個場景的幾何結構。
- `comparison.png`：AI 生成資訊圖，與真正的 Blender 渲染分開標示。

所有媒體的尺寸、MIME、位元組數、SHA-256 及來源類型見 [INDEX.json](INDEX.json)。這是圖集的個別清單，不改動安裝器 ZIP 的原有資產白名單，也不冒充人工逐像素簽核紀錄。

提示詞公開版只把私人輸出資料夾路徑替換為可讀標記；不聲稱整理後的短說明就是唯一曾送出的訊息。操作紀錄中沒有公開金鑰、通道識別字、私人聊天連結或原始 runtime log。
